# Git setup

Branch de trabalho criada:

```bash
codex/supabase-git-setup
```

Fluxo recomendado:

```bash
git status
git add .
git commit -m "Initial Facebook Ads dashboard app"
```

Para publicar no GitHub depois:

```bash
git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin codex/supabase-git-setup
```

Depois abra um PR para a branch principal.
